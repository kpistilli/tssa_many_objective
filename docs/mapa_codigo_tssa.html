Mapa del código TSSA

Cómo se conectan los 11 archivos Python del proyecto Asignación Simultánea de Estudiantes y Docentes y el script de la campaña experimental (versión del 2 de noviembre de 2026). Hay tres capas: lo que ejecutás, el núcleo del modelo y los datos. Sólo dos archivos tocan PostgreSQL.

Quién importa a quién

Cada flecha va del archivo que importa hacia el importado (A → B: A hace from B import …). Tocá o pasá el mouse sobre un archivo para ver sólo sus conexiones y su ficha abajo.

Qué pasa durante una corrida

El mismo código visto en el orden en que se ejecuta, por ejemplo con python integrated_app.py. El paso 4 es el ciclo que pymoo repite en cada generación; ahí se reparte casi todo el tiempo de cómputo.
